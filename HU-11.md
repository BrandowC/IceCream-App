# ➕ HU-11 — Admin crear producto

##  Objetivo

Permitir que el administrador cree nuevos productos (helados) desde el panel de administración mediante un formulario, para ampliar el catálogo disponible en el sistema.

## ✅ Actividades a realizar

### 1. Diseñar la estructura del producto
Definir los campos necesarios para registrar un producto, como id, nombre, descripción, precio, imagen y disponibilidad.

### 2. Crear o verificar la tabla de productos en la base de datos
Asegurar que exista la tabla `productos` en la base de datos con los campos necesarios para almacenar los nuevos helados.

### 3. Diseñar el formulario de registro de productos
Crear la interfaz en el panel de administración que permita ingresar los datos del nuevo producto.

### 4. Implementar validación de datos en el formulario
Agregar validaciones para asegurar que los datos ingresados sean correctos, por ejemplo que el nombre no esté vacío y el precio sea válido.

### 5. Desarrollar el endpoint para crear productos
Implementar en el backend un servicio o API que reciba los datos del formulario y los envíe a la base de datos.

### 6. Implementar la lógica para guardar el producto
Programar la función que inserte el nuevo producto en la tabla `productos`.

### 7. Actualizar el catálogo después de crear el producto
Asegurar que el nuevo producto aparezca automáticamente en la lista de productos del panel administrador.

### 8. Realizar pruebas de creación de productos
Verificar que al completar el formulario y guardar, el nuevo producto se registre correctamente y aparezca en el catálogo.
