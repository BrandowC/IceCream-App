# ✅ HU-08 — Confirmar pedido

##  Objetivo

Permitir que el usuario confirme su pedido desde el carrito de compras para que el sistema registre la orden y la envíe a la heladería para su preparación.

## ✅ Actividades a realizar

### 1. Diseñar la estructura de datos del pedido
Definir cómo se almacenará la información del pedido confirmado, incluyendo productos, cantidades, precio total, fecha y estado del pedido.

### 2. Crear la tabla o modelo de pedidos
Implementar en la base de datos o en el sistema la estructura necesaria para guardar los pedidos confirmados por los usuarios.

### 3. Implementar el botón "Confirmar pedido"
Agregar en la pantalla del carrito un botón que permita al usuario confirmar su compra.

### 4. Desarrollar la lógica de confirmación del pedido
Programar la función que tome los productos del carrito y los registre como un nuevo pedido en el sistema.

### 5. Guardar la información del pedido
Registrar en la base de datos todos los productos, cantidades y el total del pedido al momento de la confirmación.

### 6. Mostrar mensaje de confirmación al usuario
Implementar una notificación o pantalla que informe al usuario que su pedido fue enviado correctamente.

### 7. Limpiar el carrito después de confirmar
Vaciar el carrito una vez que el pedido haya sido registrado para evitar duplicaciones.

### 8. Realizar pruebas del proceso de confirmación
Verificar que al confirmar el pedido este se registre correctamente en el sistema y se muestre el mensaje de confirmación al usuario.
