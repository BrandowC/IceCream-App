## 🍦 HU-01 — Ver menú de helados

## Objetivo

Permitir que el usuario visualice el catálogo de helados con imagen, nombre y precio obtenidos desde la API.

## ✅Actividades

1. **Crear página Menú**
   - Crear la carpeta `src/pages/Menu` y el archivo `Menu.tsx`.
   - Agregar estructura básica de Ionic (`IonPage`, `IonHeader`, `IonContent`).

2. **Crear servicio para consumir la API**
   - Crear archivo `src/services/api.ts`.
   - Implementar función para consultar `GET /productos`.

3. **Conectar la pantalla con la API**
   - Usar `useEffect` para llamar al servicio al cargar la página.
   - Guardar los productos en un estado (`useState`).

4. **Crear componente de tarjeta de producto**
   - Crear componente `ProductoCard` en `src/components`.
   - Mostrar imagen, nombre y precio del helado.

5. **Mostrar lista de helados**
   - Recorrer la lista de productos con `.map()`.
   - Renderizar un `ProductoCard` por cada producto.

6. **Aplicar diseño visual**
   - Ajustar estilos y colores en `variables.css`.
   - Organizar las tarjetas para que el menú sea visualmente atractivo.

7. **Validar funcionamiento**
   - Ejecutar la app con `ionic serve`.
   - Confirmar que los productos se muestran correctamente desde la API.
