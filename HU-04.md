## 💰 HU-04 — Calcular precio dinámico

### Objetivo

Permitir que el sistema calcule y muestre el precio del helado en tiempo real según las opciones seleccionadas por el usuario, como sabor, toppings y tamaño.

### ✅ Actividades

1. **Definir precio base del helado**
   - Obtener el precio base del producto desde la API.

2. **Asignar precio a toppings**
   - Definir el costo adicional de cada topping.

3. **Asignar precio según tamaño**
   - Establecer costo adicional para tamaños (12, 14, 16 oz).

4. **Crear función de cálculo de precio**
   - Implementar función que sume precio base + extras seleccionados.

5. **Actualizar precio al cambiar opciones**
   - Ejecutar el cálculo cada vez que el usuario seleccione o quite una opción.

6. **Mostrar precio actualizado en la interfaz**
   - Renderizar el precio dinámico en la pantalla de personalización.

7. **Validar funcionamiento**
   - Probar diferentes combinaciones de opciones.
   - Verificar que el precio se actualice correctamente.
