# 🧑‍💼 HU-10 — Admin listar productos

##  Objetivo

Permitir que el administrador visualice el listado completo de productos disponibles en el sistema desde el panel de administración, con el fin de gestionarlos, revisarlos y administrarlos de manera eficiente.

## ✅ Actividades a realizar

### 1. Diseñar la estructura de los productos
Definir los campos que tendrá cada producto en el sistema, como id, nombre, precio, imagen, descripción y disponibilidad.

### 2. Crear o verificar la tabla de productos
Implementar o validar la tabla `productos` en la base de datos donde se almacenará la información del catálogo.

### 3. Desarrollar el endpoint para obtener productos
Crear un servicio o API en el backend que permita consultar la lista completa de productos almacenados en la base de datos.

### 4. Diseñar la interfaz del panel administrador
Crear la pantalla del panel administrativo donde se mostrará el catálogo de productos.

### 5. Mostrar la lista de productos
Implementar una tabla o lista en la interfaz que muestre los productos con información como nombre, precio y estado.

### 6. Conectar el panel con el backend
Integrar la interfaz del panel administrador con el servicio que obtiene los productos desde la base de datos.

### 7. Implementar actualización automática de la lista
Asegurar que cuando se agreguen o modifiquen productos, la lista del panel se actualice correctamente.

### 8. Realizar pruebas de visualización
Verificar que al ingresar al panel de administración el sistema muestre correctamente el catálogo completo de productos.
