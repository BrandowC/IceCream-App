## 🎨 HU-03 — Personalizar helado

### Objetivo

Permitir que el usuario personalice su helado seleccionando sabor, toppings, tipo de presentación (cono o vaso) y tamaño, guardando la configuración de forma temporal.

### ✅ Actividades

1. **Crear sección de personalización en el detalle**
   - Agregar en `DetalleProducto` el espacio donde se configurará el helado.

2. **Crear selector de sabores**
   - Mostrar lista de sabores disponibles.
   - Permitir seleccionar un sabor.

3. **Crear selector de toppings**
   - Mostrar opciones de toppings.
   - Permitir seleccionar uno o varios toppings.

4. **Crear selector de tipo de presentación**
   - Agregar opción para elegir entre **cono** o **vaso**.

5. **Crear selector de tamaño**
   - Mostrar tamaños disponibles (12, 14, 16 oz).
   - Mostrarlo solo si el usuario selecciona **vaso**.

6. **Guardar selección temporal**
   - Crear estado (`useState`) para almacenar la personalización del helado.

7. **Actualizar configuración al seleccionar opciones**
   - Cada cambio de opción debe actualizar el estado del helado personalizado.

8. **Validar funcionamiento**
   - Ejecutar la app con `ionic serve`.
   - Verificar que las opciones seleccionadas se guarden correctamente.
