## 🍨 HU-02 — Ver detalle de producto

### Objetivo

Desarrollar la pantalla de **detalle del helado** que permita al usuario visualizar la información completa del producto seleccionado desde el menú, incluyendo imagen, descripción y precio.

### ✅Actividades

1. **Crear página DetalleProducto**
   - Crear carpeta `src/pages/DetalleProducto`.
   - Crear archivo `DetalleProducto.tsx` con estructura básica de Ionic.

2. **Configurar navegación desde el menú**
   - Agregar navegación al hacer clic en un producto.
   - Enviar el `id` del helado seleccionado.

3. **Crear servicio para obtener producto por ID**
   - Agregar función en `api.ts`.
   - Implementar consulta `GET /productos/:id`.

4. **Obtener datos del producto**
   - Usar `useEffect` para llamar la API al cargar la pantalla.
   - Guardar el producto en un estado (`useState`).

5. **Mostrar información del producto**
   - Mostrar imagen del helado.
   - Mostrar nombre, descripción y precio.

6. **Preparar sección de opciones**
   - Crear espacio en la interfaz para mostrar opciones de personalización.

7. **Validar funcionamiento**
   - Ejecutar la aplicación con `ionic serve`.
   - Verificar que al seleccionar un helado se muestre su detalle correctamente.
