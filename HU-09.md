# 💾 HU-09 — Guardar pedido en base de datos

##  Objetivo

Permitir que el sistema almacene los pedidos confirmados en la base de datos PostgreSQL, guardando la información del pedido, los productos incluidos y el total de la compra, con el fin de mantener un registro de ventas.

## ✅ Actividades a realizar

### 1. Diseñar el modelo de datos de pedidos
Definir la estructura de las tablas necesarias para almacenar los pedidos, incluyendo información como id del pedido, fecha, total y estado.

### 2. Crear las tablas en la base de datos
Implementar en PostgreSQL las tablas necesarias, por ejemplo `pedidos` y `detalle_pedido`, para guardar la información del pedido y sus productos.

### 3. Definir la relación entre pedidos y productos
Establecer la relación entre las tablas para que un pedido pueda contener varios productos con sus respectivas cantidades y precios.

### 4. Desarrollar el endpoint o servicio en el backend
Crear una API o servicio que reciba la información del pedido confirmado desde la aplicación.

### 5. Implementar la lógica para guardar el pedido
Programar la función que procese los datos recibidos y los inserte correctamente en las tablas de la base de datos.

### 6. Guardar los productos del pedido
Registrar cada producto del pedido en la tabla de detalle, incluyendo cantidad, precio y referencia al pedido.

### 7. Validar los datos antes de guardar
Verificar que la información del pedido sea correcta antes de almacenarla en la base de datos.

### 8. Realizar pruebas de persistencia
Probar que al confirmar un pedido, este se almacene correctamente en PostgreSQL con todos sus productos y el total correspondiente.
