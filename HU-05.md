# 🛒 HU-05 "Agregar al carrito"

##  Objetivo

Permitir que el usuario agregue un helado personalizado al carrito de compras dentro de la aplicación, almacenando las configuraciones seleccionadas (por ejemplo tamaño o toppings) para que el producto quede listo para ser revisado y comprado posteriormente.

## ✅ Actividades a realizar

### 1. Diseñar la estructura del carrito
Definir cómo se almacenarán los productos agregados al carrito, incluyendo campos como id del producto, nombre, precio, cantidad y opciones seleccionadas.

### 2. Crear la tabla o modelo de carrito
Implementar en la base de datos o en el modelo de la aplicación la estructura que permitirá guardar los productos agregados al carrito.

### 3. Desarrollar la lógica para agregar productos
Programar la función que permitirá añadir un helado personalizado al carrito cuando el usuario lo seleccione.

### 4. Implementar el botón "Agregar al carrito"
Diseñar y agregar en la interfaz de usuario el botón que permitirá enviar el producto configurado al carrito de compras.

### 5. Capturar las opciones del helado personalizado
Registrar las opciones que el usuario haya seleccionado (por ejemplo tamaño, sabor o toppings) para guardarlas junto con el producto en el carrito.

### 6. Actualizar el carrito en la interfaz
Mostrar visualmente que el producto fue agregado, ya sea actualizando el contador del carrito o la lista de productos agregados.

### 7. Conectar la interfaz con la lógica del carrito
Integrar la interfaz de usuario con la función que guarda los productos en el carrito para que el proceso funcione correctamente.

### 8. Realizar pruebas del flujo de agregado
Verificar que al presionar "Agregar al carrito" el producto personalizado aparece correctamente en el carrito y queda listo para compra.
