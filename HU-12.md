# ✏️ HU-12 — Admin editar producto

##  Objetivo

Permitir que el administrador edite la información de los productos existentes en el sistema desde el panel de administración, con el fin de mantener actualizado el catálogo de helados.

## ✅ Actividades a realizar

### 1. Diseñar la funcionalidad de edición de productos
Definir qué campos del producto podrán modificarse, como nombre, descripción, precio, imagen o disponibilidad.

### 2. Crear la interfaz de edición en el panel administrador
Diseñar la pantalla o formulario que permitirá al administrador modificar la información del producto.

### 3. Cargar los datos actuales del producto
Implementar la lógica para que al abrir la opción de edición se muestren los datos actuales del producto seleccionado.

### 4. Implementar validación de datos
Agregar validaciones en el formulario para asegurar que los datos modificados sean correctos antes de guardarlos.

### 5. Desarrollar el endpoint para actualizar productos
Crear en el backend un servicio o API que reciba los cambios realizados por el administrador.

### 6. Implementar la lógica de actualización en la base de datos
Programar la función que actualice los datos del producto en la tabla `productos`.

### 7. Actualizar el catálogo después de editar
Asegurar que los cambios realizados se reflejen correctamente en la lista de productos del sistema.

### 8. Realizar pruebas de edición
Verificar que al modificar la información de un producto y guardar, los cambios se actualicen correctamente en el menú.
